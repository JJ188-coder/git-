# Lecture

Lecture 是一款只在本机运行的 macOS 英文课堂助手。双击应用后，它会在菜单栏运行，并打开本地网页。

## 功能

- 使用 Mac 麦克风保存完整课堂录音
- macOS 本地实时英文识别，保存时间轴和可信度
- Apple 本地英文到简体中文低延迟翻译
- 课程词汇表辅助专业术语识别
- 课后本地远场长录音复核，实时稿与复核稿分别保留
- DeepSeek 校正中文、生成学习总结并做带时间引用的问答
- 课程历史、重点标记、录音跳转和可恢复处理
- API Key 仅存放在 macOS 钥匙串；音频不会上传

## 使用

1. 打开 `/Applications/Lecture.app`。
2. 首次使用时允许麦克风和语音识别权限。
3. 在“课程历史”中新建课程，可加入专业词汇。
4. 在“实时课堂”选择课程并开始。关闭网页不会停止录音；菜单栏的 `L.` 可重新打开。
5. 结束后保留原录音，本地复核英文，并在配置 DeepSeek 后生成校正翻译和总结。

准确度受教授距离、回声、口音和噪声影响。Lecture 不承诺 100% 正确，而是保留原音频、时间轴、可信度与多版本文本，保证可核对。
